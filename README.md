---

## Overview

The **ISLANDS Programme App** is an end-to-end monitoring and reporting platform designed to support the management of programme and project performance data.

The application provides a structured workflow for capturing, managing, validating and visualizing programme monitoring information, including projects, components, indicators, baselines, targets and progress.

### Core Purpose

- Standardize programme monitoring and reporting data
- Improve consistency of indicator reporting across projects
- Support structured data entry and validation
- Enable monitoring of indicator performance against targets
- Provide a centralized view of programme-level results
- Support evidence-based programme management and reporting

---

## Key Capabilities

| Capability | Description |
|---|---|
| **Data Entry** | Structured interface for capturing project and monitoring information |
| **Indicator Management** | Manage components, indicators and sub-indicators |
| **Baseline & Targets** | Record baseline values and programme targets |
| **Progress Tracking** | Monitor actual performance against targets |
| **Data Validation** | Support consistency and quality checks |
| **Reporting** | Organize monitoring information for programme reporting |
| **Dashboard** | Visualize programme performance and indicator results |

# ISLANDS GEB Portal

Standalone PHP/MySQL monitoring and reporting portal for ISLANDS GEB reporting.

## Permanent application
- Folder: `C:\xampp\htdocs\islands_geb_portal`
- URL: `http://localhost/islands_geb_portal/`
- Login: `http://localhost/islands_geb_portal/login.php`

## Workflow and notifications
- Any authenticated user can route a submission to Draft, Review, Approval or Completed.
- The person assigned as Reviewer receives Review-stage notifications at their own email address.
- The person assigned as Approver receives Approval-stage notifications at their own email address.
- Assignment changes notify the new assignee.
- Reviewer/Approver names and email addresses are shown on the submission and workflow screens.
- Email failures are logged without undoing a successful workflow transition.

## Branding
The supplied ISLANDS logo is used throughout the portal, with a blue/teal visual treatment and clean institutional layout inspired by the public GEF ISLANDS programme materials.


## CSV / Excel Export
The portal now provides authenticated exports from the GEB Submissions page.
- CSV: `export.php?format=csv`
- Excel: `export.php?format=xlsx`
- Search, workflow status and reporting-year filters are preserved when using the export buttons.
- The Excel output is a native `.xlsx` workbook generated by PHP when the XAMPP PHP ZipArchive extension is enabled.
- Export includes project, indicator, reporting period, values, units, disaggregation, evidence, workflow status, submitter/reviewer/approver and timestamps.

## JSON API

The MVP includes a token-protected JSON API at:

`http://localhost/islands_geb_portal/api.php`

### Authentication

Use an HTTP Bearer token:

`Authorization: Bearer ISLANDS-GEB-API-2026`

The token is stored as a SHA-256 hash in the `api_tokens` table. For production, replace the seeded local token with a securely generated secret and serve the API over HTTPS.

### Examples

Completed records (default):

`GET /api.php`

All workflow states:

`GET /api.php?state=all`

Filter by year/project/indicator/country:

`GET /api.php?year=2026&project=10261&indicator=GEF%20%239.6&country=Jamaica`

Search and paginate:

`GET /api.php?q=Jamaica&page=1&per_page=100`

The JSON response includes project, indicator, reporting value, disaggregation, evidence/source information, workflow state, submitter/reviewer/approver and timestamps. The API defaults to Completed records so downstream dashboards do not accidentally consume drafts; `state=all` is available for controlled QA/integration use.
